# Uchiha: Multipurpose Discord Bot (discord.js)

**Uchiha** is a multipurpose **Discord bot written in JavaScript with discord.js**: moderation, giveaways, games, image generation, info commands and cross-server phone calls, with 80+ commands across nine categories.

## Command categories

| Category | Examples |
|---|---|
| 🛡️ Moderation | Keep your server in order |
| 🎉 Giveaways | Run giveaways with automatic winners |
| 🎮 Games | Mini-games for your members |
| 😂 Fun | Fun and social commands |
| 🖼️ Image | Image generation |
| ℹ️ Info | Server, user, weather and Urban Dictionary lookups |
| ☎️ Phone | call another server through the bot |
| 🔧 Misc and owner tools | utility and admin commands |

## Run it

```bash
git clone https://github.com/Drix10/Uchiha.git
cd Uchiha
npm install
# set your token and prefix in config.js
node index.js
```

Originally hosted on Glitch. The [first version of Uchiha Bot](https://github.com/Drix10/Uchiha-bot) was my first public Discord bot.
